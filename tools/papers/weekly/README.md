## 脚本顺序

1. `01_probe_sgexam.py` — 抓 sgexam.com P5/P6 四科索引页里 2024–2026 的链接 → `sg_links.json`。站上只有学校卷, **没有 PSLE 真题**。
2. `02_dl_top10_p5_p6.py` — 十校 P5 年终考 + P6 Prelim 下载 (Google Drive 直链, 已有的从 `P6顶尖小学真题2025` 复制)。
3. `03_dl_wa1.py` / `04_dl_wa2.py` — P6 第一/第二学期小测 (WA1/WA2/课堂测验/非计分测验)。
4. `05_ocr_all.py` — 扫描件没有文字层, 每页 OCR 上 40% (RapidOCR, 6 进程, 每份约 40s) → `all_pages.json`; `06_ocr_need.py` 只补清单里缺的。Prelim 复用 `../pages.json` 的页标签。
5. `07_plan_weekly.py` — 生成清单 docx (这是 v9/v10 版本的生成器; v11/v12 是另一个会话在此基础上改的第 1–6 周)。`08_audit_plan.py` 核对清单里每个文件存在、无重复、按学校×类别×年份汇总。
6. `09_build_print_packs.py [周次...]` — 读清单 docx, 每份卷子拆 题目/答案 (规则见下), 加封面(第 N 周第 k 份/做什么/限时/得分栏), 按 `年月/第NN周` 落盘, 生成 `目录.txt`、`打印.py`、每月 bat。`build_flags.json` 列出可疑拆分, 必须人工看。
7. `twoup_print.py` — **省纸打印版 (一面拼两页/删空白/不带答案/每份从新纸开始), 带强制自检**, 出文件前逐半面和原卷图像比对, 不过不保存。详见文件头 docstring 和 memory `feedback_psle_print_twoup_selfcheck`。`print_folder.py` 是早期按文件夹直打的版本 (横向 2-up + Duplex=3), 已被 twoup_print 取代。

## 拆分规则 (09 里 `split()`)

- 答案页: 从 40% 处往后第一页命中 `ANSWER KEY / 参考答案 / MARKING SCHEME / SCHOOL…SUBJECT…LEVEL / Q1|Q2|Q3 表头 / Corrections for`; 识别不到的人工写进 `AOV` 字典 (已有 7 份)。
- 英文: 去掉 Paper 1 作文 (Situational/Continuous Writing) 和听力练习卷, 从正卷 "questions 1 to 10" 那页的封面开始。
- 华文: 去掉试卷一作文和听力, 从 "试卷二 / Paper 2" 封面开始。
- 数学、科学: 整份。
- 原卷有 `/Rotate` 旋转标记 (Rosyth/HenryPark 270°, 公教 180°), 拼页前必须 `remove_rotation()` —— 2026-11-21 因此打错一周, 见 memory。

## 周清单的口径 (v9 起, PSLE 专家方案 + 老板定稿)

- 每周: 英文、科学各两份 (上学周 = 预考整卷 + 小测; 假期 = 两份整卷); 数学、华文隔周一份, 空周只做错题。
- 顺序: 寒假 P5 难校 (仅英科; 数华从 P6 预考 2024 开始, v11/v12) → 1 月起只做 P6 → 2025 预考 → 2026 新题型压轴 (6–7 月) → 7/26 起 PSLE 真题校准 + 整卷二刷 → 口试周只做两份, 学校预考两周不做家庭卷 → 9 月真题 2025/2026。
- 2024 数学预考是旧考法 (卷一 45 分/60 分钟, 含速度题), 不排进主计划; 科学 2024 用来练关键词。
- 刷几遍: 新卷一遍; 每周日 40 分钟滚动重做一周前和四周前的错题; 整卷二刷只做 <85% 的卷子; 9 月错题本从头过一遍。
- 英文只做 Paper 2; 作文走老师的范文和第二稿。
- 2027 年 PSLE 日期未公布, 第 38–44 周按 2026 年考评局时间表推算。

## 判分报告 (2026-11-22 起)

- `aitong_report.py` + `aitong_v3_expl.py` + `sim_items.py`: 爱同 2024 P5 英文 Paper 2 判分报告生成器 (v5 结构 = 老板定稿: 判分依据一行 → 一、结论固定句 → 二、分项表 → 三、逐题解析(不用表格, 每题末尾附"名校预考里考过的同类题") → 给了分要留意 → 四、丢分规律 → 五、差距与目标)。以后判别的卷子照这个结构改数据。
- 严格按 PSLE 考官标准: 采分点少一个不给, 添原文没有的内容扣分, 不给半分, 不扣语法分。
- 同类题检索: `ocr_eng_full.py` 把 2024–2026 英文预考的选择题/填空/改错页整页 OCR → `eng_full.json`; `find_similar.py` 抽 Booklet A 题 (题干+四选项) 按考点分类; `find_similar2.py` 按页面文本窗口搜填空/改错考点。命中后一律渲染原页和答案页人工核对再写进 `sim_items.py`, OCR 文本不直接引用。
